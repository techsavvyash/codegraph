Strategies emit into disjoint bands: semlink scores land in 0.30–0.60, docmine in 0.70–0.95. Because the bands never overlap, a single confidence value is comparable across strategies — any docmine edge outranks any semlink edge, and thresholds can be set globally without knowing which strategy produced an edge.
