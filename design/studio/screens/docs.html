Layer S › semlink

Where docmine stops at explicit identifiers, semlink covers prose that never names a symbol. Each chunk is summarized, embedded, and matched against candidate summaries of code in the same service. The fan-out lives in matchChunks()0.90, which the pipeline enters through Runner.Run()0.48; an LLM judge then accepts or rejects each candidate pair before any MENTIONS edge is written.

Candidate pairs scoring below semlink.similarity_threshold are discarded before the judge ever runs, and every accepted judgment debits the run budget through spendBudget()0.57. The defaults ship conservative:

semlink:
  provider: tbd            # vendor unchosen
  similarity_threshold: 0.55
  judge: enabled
  max_budget_usd: 5.00
